SyncSub 測試說明

這是雙邊即時字幕測試頁。請用 Chrome 或 Edge，雙方各自開一個視窗，輸入相同房號，並使用你自己的 Gemini API Key（翻譯費用算在你自己的帳號）。

  1. 到 Google AI Studio 免費建立 API Key（登入 Google 帳號 → Create API key）。
  2. 點下方按鈕進入測試會議室。
  3. 填寫顯示名稱、房號、身分（台灣端／日本端），並貼上你的 API Key。
  4. 與對方約定好同一個房號後按「進入測試會議室」→「開始收音」。
  5. 請允許瀏覽器使用麥克風。建議把視窗放在 Zoom 旁邊對照字幕。
