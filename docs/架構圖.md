# SyncSub 架構圖

> 更新：2026-09-08  
> Zoom 傳聲音；SyncSub 傳雙語字幕。

---

## 1. 整體架構（誰做什麼）

```mermaid
flowchart TB
  subgraph Zoom["Zoom 會議（只傳聲音）"]
    ZW[台灣端聽對方]
    ZJ[日本端聽對方]
  end

  subgraph TW["台灣端 Chrome"]
    MicTW[麥克風]
    SpeechTW[Web Speech API<br/>語音 → 中文文字]
    UITW[SyncSub UI<br/>看日文譯文]
    MicTW --> SpeechTW --> UITW
  end

  subgraph JP["日本端 Chrome"]
    MicJP[麥克風]
    SpeechJP[Web Speech API<br/>語音 → 日文文字]
    UIJP[SyncSub UI<br/>看中文譯文]
    MicJP --> SpeechJP --> UIJP
  end

  subgraph Relay["中繼站 Node（Express + Socket.io）"]
    Rooms[房間管理]
    Queue[翻譯佇列]
    Translate[translate.js]
    Rooms --> Queue --> Translate
  end

  subgraph AI["翻譯 API"]
    Gemini[Gemini]
    MM[MyMemory 備援]
    Gemini --- MM
  end

  SpeechTW -->|Socket.io send_speech| Rooms
  SpeechJP -->|Socket.io send_speech| Rooms
  Translate --> Gemini
  Rooms -->|receive_original / receive_translation| UITW
  Rooms -->|receive_original / receive_translation| UIJP

  ZW -.->|聲音| ZJ
  ZJ -.->|聲音| ZW
```

**重點：** 不抓 Zoom 系統音；雙方各自開 SyncSub，用**自己的麥克風**。

## 2. 部署／入口（同一套服務，兩種對外方式）

```mermaid
flowchart LR
  subgraph Clients["使用者瀏覽器"]
    Public["公開：/ 說明、/try 測試"]
    Host["自用：/r/&lt;token&gt;"]
  end

  subgraph Edge["對外 HTTPS / WSS"]
    Railway["Railway<br/>*.up.railway.app"]
    Tunnel["Cloudflare Tunnel<br/>*.trycloudflare.com"]
  end

  subgraph App["zoom-sync-translator"]
    Express[Express 靜態頁 + /health]
    IO[Socket.io 中繼]
    Env[".env / Variables<br/>GEMINI_API_KEY<br/>HOST_LOBBY_TOKEN"]
  end

  Public --> Railway
  Public --> Tunnel
  Host --> Railway
  Host --> Tunnel
  Railway --> Express
  Tunnel --> Express
  Express --> IO
  IO --> Env
```

| 入口 | 路徑 | 翻譯誰付錢 |
|------|------|------------|
| 公開說明 | `/` | — |
| 公開測試 | `/try`（舊 `/guest`） | 測試者自己的 Key（BYOK） |
| 站長自用 | `/r/<HOST_LOBBY_TOKEN>` | 伺服器 `GEMINI_API_KEY` |

## 3. 一句話資料流（時間序）

```mermaid
sequenceDiagram
  participant TW as 台灣 Chrome
  participant S as 中繼站
  participant G as Gemini
  participant JP as 日本 Chrome

  TW->>TW: Web Speech 辨識完成
  TW->>S: send_speech（原文）
  S-->>JP: receive_original（先看原文）
  S->>G: 翻譯請求
  G-->>S: 譯文
  S-->>TW: receive_translation
  S-->>JP: receive_translation（日文字幕）
  Note over TW,JP: UI 顯示 RTT｜譯 ms
```

## 5. 額度分流（公開 vs 自用）

```mermaid
flowchart TD
  Join[join_room] --> Guest{guestLane?}
  Guest -->|是 /try| NeedKey{有 apiKey?}
  NeedKey -->|否| Reject[拒絕進房]
  NeedKey -->|是| BYOK[translator.mode = byok]
  Guest -->|否 自用頁| ServerMode[mode = server<br/>用 GEMINI_API_KEY]
  BYOK --> Speech[send_speech]
  ServerMode --> Speech
  Speech --> T{用誰的 Key?}
  T -->|byok| ClientKey[客戶 Key → Gemini]
  T -->|server| HostKey[環境變數 Key → Gemini]
```
