## 自用會議室（勿外傳）

預設 token（與 `.env.example`／程式預設一致；若你在 Railway 改過 `HOST_LOBBY_TOKEN`，以你改的為準）：

```
https://zoom-sync-translator-production.up.railway.app/r/ss-73c8b2b0
```

本機：

```
http://localhost:3100/r/ss-73c8b2b0
```

建議：瀏覽器書籤收藏完整 URL。更換密鑰時在 Railway Variables 設定 `HOST_LOBBY_TOKEN`（僅英數、`-`、`_`），部署後舊網址會失效。

本機 `npm start` 時，啟動 log 也會印出「自用入口 …（勿外傳）」。

---

## 自己開會（最短步驟）

1. 雙方開啟**自用會議室**網址（同一路徑）。
2. 選台灣端／日本端、填**相同房號**（可用 URL `?room=xxx&role=jp&name=田中` 預填）。
3. 進入 →「開始收音」→ 允許麥克風。
4. Zoom 傳聲音；本頁看字幕。可隱藏控制列；結束可匯出逐字稿。

不必在自用頁貼 API Key（除非你想臨時改走 BYOK）。

---

## 給別人測（你要做的）

1. 只傳公開說明或 `/try`，或整份 [給測試者的說明.md](./給測試者的說明.md)。
2. **不要**傳 `/r/...`。
3. 對方各自準備 Gemini Key；費用不進你的伺服器 Key。

---

## Railway 變數檢查

| 變數 | 建議 |
|------|------|
| `GEMINI_API_KEY` | 已設定（自用翻譯） |
| `TRANSLATE_PROVIDER` | `gemini` |
| `TRUST_PROXY` | `1` |
| `HOST_LOBBY_TOKEN` | 可改成更長亂數 |
| `REQUIRE_CLIENT_API_KEY` | 通常 `false`（公開測試已由 `/try` 強制 BYOK） |

驗證：`GET …/health` → `ok: true`，`env.hasGeminiKey: true`。

---

## 本機開發

```bash
cp .env.example .env   # 填 GEMINI_API_KEY；可改 HOST_LOBBY_TOKEN
npm install && npm start
```

- 說明：http://localhost:3100/
- 測試：http://localhost:3100/try
- 自用：http://localhost:3100/r/<HOST_LOBBY_TOKEN>

---

## 資安提醒

- 自用路徑是「秘密 URL」，不是登入系統；外洩等同開放他人用你的額度開會。
- 勿把 `.env`、API Key、自用完整 URL 貼進公開 Issue／群組／測試說明。
- 懷疑外洩時：立刻改 `HOST_LOBBY_TOKEN` 並 Redeploy；必要時輪換 `GEMINI_API_KEY`。
