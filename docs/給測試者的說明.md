## 怎麼測（約 5 分鐘）

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 登入 Google，建立免費 **Gemini API Key**（Create API key）。
2. 開啟上方「測試會議室」網址。
3. 填寫：
   - **顯示名稱**
   - **房號**（與對方約定同一個，例如 `test-001`）
   - **身分**：台灣端（說中文）或日本端（說日文）
   - **你自己的** API Key（必填）
4. 按「進入測試會議室」→「開始收音」→ 允許麥克風。
5. 建議把瀏覽器放在 Zoom 旁邊：Zoom 聽聲音，本頁看字幕。

雙方都要開**同一個測試會議室網址**、填**同一個房號**，一邊說中文、一邊說日文即可對測。

---

## 請注意

- 翻譯費用算在**你自己的** Google 帳號；請用自己的 Key，不要共用別人的 Key。
- 請只使用本說明列出的網址；其他路徑不是給測試用的。
- 需外網；辨識品質受麥克風與環境噪音影響。
- 測完可到 AI Studio 刪除或停用該 Key。

---

## 常見問題

**進不了會議室？**  
通常是沒貼 API Key，或 Key 複製不完整。

**聽得到 Zoom 但沒字幕？**  
確認已按「開始收音」、音量條有跳動，且對方也在同一個房號。

**翻譯失敗？**  
檢查 Key 是否有效、AI Studio 是否尚有免費額度；稍候再試。
