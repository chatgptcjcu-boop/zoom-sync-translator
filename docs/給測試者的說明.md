# SyncSub 雙語字幕 — 給測試者的說明

請用 **Chrome** 或 **Edge**（需允許麥克風）。

## 測試網址（請用這個）

1. **說明頁**：https://zoom-sync-translator-production.up.railway.app/
2. **直接進會議室**：https://zoom-sync-translator-production.up.railway.app/try

## 怎麼測

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 免費建立自己的 **Gemini API Key**。
2. 開啟上方測試網址，填寫：
   - 顯示名稱
   - 與對方約定的**相同房號**
   - 身分（台灣端說中文／日本端說日文）
   - **你自己的** API Key
3. 進入會議室後按「開始收音」。
4. 建議把瀏覽器視窗放在 Zoom 旁邊對照字幕。

## 注意

- 翻譯費用算在**你自己的** Google 帳號，請用自己的 Key。
- 雙方都要開**同一個測試網址**與**同一個房號**。
- 請只使用本說明提供的網址；其他路徑不是給測試用的。
