## 2. 兩邊差異（摘要）

| 項目 | 公開版 `/`、`/try` | 自用版 `/r/<token>` |
|------|-------------------|---------------------|
| 給誰 | 外部測試者 | 站長自己開會 |
| 頁面 | 說明 `public/index.html`；會議室 `server/pages/try.html` | `server/pages/host.html` |
| 翻譯誰付錢 | 測試者自己的 Gemini API Key（BYOK） | 伺服器環境變數 `GEMINI_API_KEY` |
| 沒填 API Key | `/try` **不能進房** | 可進房（用伺服器額度） |
| 前端旗標 | `__SYNCSUB_GUEST__` → `guestLane: true` | `__SYNCSUB_HOST__` → 伺服器額度 |
| 版權頁腳 | 有（宜彤彥科技／統編／教育免費授權） | 無強制公開版權文案 |
| 可否寫進測試說明 | ✅ | ❌ |

## 3. URL 查詢參數（兩邊會議室共用）

在 `/try` 或自用 `/r/...` 後面加參數，可預填大廳欄位（**不會**把 API Key 寫進網址）：

| 參數 | 範例 | 說明 |
|------|------|------|
| `room` | `room=test-001` | 預填會議房號 |
| `role` | `role=jp` 或 `role=tw` | 預選日本端／台灣端（`jp` 會切語系） |
| `name` | `name=田中` | 預填顯示名稱 |
| `server` | `server=https://…` | 進階：指定中繼站（通常空白＝本站） |

### 公開版範例

```
https://zoom-sync-translator-production.up.railway.app/try?room=test-001&role=tw&name=小明
https://zoom-sync-translator-production.up.railway.app/try?room=test-001&role=jp&name=Tanaka
```

### 自用版範例（勿外傳）

```
https://zoom-sync-translator-production.up.railway.app/r/ss-73c8b2b0?room=meeting-001&role=tw&name=張老師
https://zoom-sync-translator-production.up.railway.app/r/ss-73c8b2b0?room=meeting-001&role=jp&name=田中
```

進房成功後，瀏覽器位址列會改寫為「目前路徑 + `room` + `role`」（仍**不含** API Key）。

## 4. 進房時送出的參數（Socket `join_room`）

前端經 Socket.io 送給伺服器（**不是**網址 query）：

| 欄位 | 公開版 `/try` | 自用版 |
|------|---------------|--------|
| `roomId` | 必填 | 必填 |
| `displayName` | 選填（有預設） | 選填 |
| `role` | `tw` / `jp` 等 | 同左 |
| `myLang` / `targetLang` | 依身分自動帶 | 同左 |
| `guestLane` | **`true`**（強制 BYOK） | `false`／未送 |
| `apiKey` | **必填**（測試者自己的 Gemini Key） | 通常空白＝用伺服器 Key |
| `apiModel` | 預設 `gemini-2.5-flash` | 僅在自備 Key 時有意義 |

伺服器行為：

- `guestLane === true` 且沒有 `apiKey` → 拒絕進房  
- BYOK 翻譯 provider 標記為 `gemini-byok`；失敗可降級 MyMemory，**不**改用站長 Key  
- 自用無 Key → `translator.mode = server`，走環境變數 Gemini

## 5. 環境變數（與兩版入口相關）

| 變數 | 預設／建議 | 影響哪一版 |
|------|------------|------------|
| `HOST_LOBBY_TOKEN` | `ss-73c8b2b0` | **自用版路徑** `/r/<此值>` |
| `GEMINI_API_KEY` | （必填才能自用翻譯） | **自用版**額度 |
| `GEMINI_MODEL` | `gemini-2.5-flash` | 自用；公開 BYOK 也可在頁面另選 |
| `TRANSLATE_PROVIDER` | `gemini` | 自用引擎鏈 |
| `REQUIRE_CLIENT_API_KEY` | `false` | `true` 時連自用頁也強制貼 Key（一般不必） |
| `TRUST_PROXY` | Railway 建議 `1` | 部署 |
| `PORT` | 本機 `3100` | 本機 |
| `CORS_ORIGIN` | 正式宜鎖網域 | 部署 |

完整範本見專案根目錄 `.env.example`。
