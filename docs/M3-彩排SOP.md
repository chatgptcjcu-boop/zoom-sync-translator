# M3 — 彩排 SOP

## 目標

在正式對教授開會前，用 **兩台裝置（或一般視窗 + 無痕）+ Zoom** 走完整場流程，確認收音、字幕、重連與操作習慣。

## 前置

- [ ] M1 完成：Railway HTTPS 可開  
- [ ] M2 完成：DeepL 已接（彩排務必用正式引擎）  
- [ ] 雙方皆為 **Chrome 或 Edge**  
- [ ] 準備有線／筆電麥克風；關閉會搶麥的其他 App  

## 彩排腳本（約 20 分鐘）

### 0. 會前 5 分

```bash
curl -s https://你的網域/health | python3 -m json.tool
npm run smoke -- https://你的網域
```

約定房號：`mtg-rehearsal-001`

連結範例：

- 台灣端：`https://你的網域/?room=mtg-rehearsal-001&role=tw&name=彩排台灣`  
- 日本端：`https://你的網域/?room=mtg-rehearsal-001&role=jp&name=彩排日本`  

### 1. 進房（3 分）

1. 兩端開啟連結 → 進入會議室  
2. 確認「房間人數：2」  
3. 連線燈為綠色／狀態「已連線」  

### 2. 麥克風（3 分）

1. 兩端按「開始收音」、允許權限  
2. 音量條會跳動  
3. 說一句短句，己方出現原文與譯文  

### 3. 雙向翻譯（5 分）

| # | 說話端 | 測試句 | 對方應看到 |
|---|--------|--------|------------|
| 1 | 台灣 | 今天想討論合作時程 | 中文原文 + 日文譯文 |
| 2 | 日本 | よろしくお願いします | 日文原文 + 中文譯文 |
| 3 | 台灣 | 下個月可以安排線上會議嗎 | 譯文合理 |
| 4 | 日本 | 資料は来週送ります | 譯文合理 |

### 4. 與 Zoom 並用（5 分）

1. 開 Zoom 測試會議（可自己兩個帳號或同事）  
2. SyncSub 視窗放側邊／第二螢幕  
3. 一邊說話：Zoom 聽聲音、SyncSub 看字幕  
4. 隱藏控制列（⌃），確認字幕仍可讀  

### 5. 異常演練（4 分）

| 動作 | 期望 |
|------|------|
| 暫時關閉 Wi-Fi 10 秒再打開 | 自動重連、可繼續收音 |
| 一方停止收音再開始 | 正常恢復 |
| 會議中**不要** Railway Redeploy | （只口頭確認規則） |

### 6. 收尾

1. 匯出逐字稿（↓）確認內容  
2. 離開房間  
3. 填寫下方紀錄
