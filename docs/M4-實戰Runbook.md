# M4 — 實戰 Runbook（對日本教授）

## 目標

正式 Zoom 會議中穩定使用 SyncSub，雙邊同步字幕協助溝通。

## 會前 24 小時

- [ ] Railway 服務 Running；近 24h 無異常重啟風暴  
- [ ] DeepL 配額足夠（控制台確認）  
- [ ] 約定房號（難猜）：例如 `mtg-20260815-tanaka`  
- [ ] 準備兩則連結（傳給自己／教授）：

```
台灣端：
https://{DOMAIN}/?room=mtg-YYYYMMDD-xxx&role=tw&name=你的名字

日本端：
https://{DOMAIN}/?room=mtg-YYYYMMDD-xxx&role=jp&name=教授名字
```

- [ ] 用一句話告知對方（可中／英／日）：

> 會議時請用 Chrome 開啟上方連結，允許麥克風，並與 Zoom 並排顯示。此工具只產生翻譯字幕，不會錄製 Zoom 畫面。

- [ ] 自己先開連結確認大廳正常（勿在此時 Redeploy）

## 會前 30 分鐘

```bash
curl -s https://{DOMAIN}/health
npm run smoke -- https://{DOMAIN}
```

- [ ] health `ok: true`，providers 含 `gemini`  
- [ ] smoke OK  
- [ ] 關閉會搶麥的軟體；選對 Chrome 麥克風裝置  

## 會前 5 分鐘

- [ ] 開 Zoom（如常）  
- [ ] 開 SyncSub 連結 → 進入 → **開始收音**  
- [ ] 確認房間人數（教授進房後應 ≥ 2）  
- [ ] 與教授做 10 秒「你好／こんにちは」字幕測試  

## 會議中規則

| 做 | 不要做 |
|----|--------|
| 句子說完稍停，利於辨識定稿 | 開會中 Redeploy Railway |
| 看字幕為輔、聽 Zoom 為主 | 依賴 MyMemory |
| 連線變黃時暫停發言等重連 | 把房號公開貼社群 |
| 專有名詞可打字於 Zoom 聊天補強 | 期望工具聽進 Zoom 對方喇叭聲 |

故障時快速降級：

1. 重連 SyncSub（重新整理、再進房）  
2. 仍失敗 → 改 Zoom 聊天打字／放慢語速  
3. 口頭說明「字幕工具暫時中斷」  

## 會後 10 分鐘

- [ ] 停止收音、匯出逐字稿存檔  
- [ ] 離開房間  
- [ ] 簡短會後紀錄（下方）
